# Plan — Die Harfe bekommt sichtbare Saiten (Issue #101)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Harfe im Katalog sieht aus wie eine Harfe, und man sieht ihre
sieben Saiten.

**Architecture:** Kein neues Subsystem, keine neue Datei. Geändert wird genau
**eine Funktion**: `harfe()` in `js/models.js:354-372`. Der Rahmen wird über
drei Eckpunkte (Korpusfuss, Knoten, Säulenkopf) neu gesetzt, sodass der
Innenwinkel am Knoten von 158° auf 114° fällt; die Saiten rechnen sich aus
diesen Eckpunkten aus und hängen an den Aussenkanten von Korpus und Hals statt
auf deren Achsen. Alles ausserhalb der Funktion — Katalogeintrag, `id`,
Spielstand-Format, Platzierung — bleibt unangetastet.

**Tech Stack:** Vanilla ES-Module, three.js r184. Kein Build, kein
Test-Runner. Verifikation ist headless Playwright.

**Spec:** `docs/ai-notes/specs/2026-09-27-harfe-design.md`

        const w = window.wipfelkratzer, T = w.THREE;
        w.floorGroup(0);
        const m = w.placeItemMesh(0, { id: 'harfe', cell: 0, x: 0, z: 0, rot: 0 });
        m.updateWorldMatrix(true, true);

        /* Teile einsammeln */
        const saiten = [], teile = {};

          if (!o.isMesh) return;
          if (o.userData.saite !== undefined) saiten[o.userData.saite] = o;
          if (o.userData.teil) (teile[o.userData.teil] = teile[o.userData.teil] || []).push(o);
        });

        /* Endpunkte eines bar()-Quaders: lokale y-Achse, Länge aus der Geometrie */
        const ende = (o, s) => o.localToWorld(
          new T.Vector3(0, s * o.geometry.parameters.height / 2, 0));

        const bb = new T.Box3().setFromObject(m);
        const ctr = bb.getCenter(new T.Vector3());

        /* 1. Sichtbarkeit: aus zwei Blickrichtungen muss der erste Treffer
              auf die Saitenmitte die Saite selbst sein. */
        const blicke = [new T.Vector3(0, 0.15, 1.9), new T.Vector3(0.9, 0.7, 1.6)];
        const sichtbar = blicke.map(off => {
          const auge = ctr.clone().add(off);
          return saiten.map(s => {
            const mid = ende(s, 1).add(ende(s, -1)).multiplyScalar(0.5);
            const r = new T.Raycaster(auge, mid.clone().sub(auge).normalize());
            const hit = r.intersectObject(m, true)[0];
            return !!hit && hit.object === s;
          }).filter(Boolean).length;
        });

        /* 2. Keine Saite steckt im Korpus (OBB-Test im Korpus-Eigensystem). */
        const korpus = teile.korpus[0];
        const inv = new T.Matrix4().copy(korpus.matrixWorld).invert();
        const kp = korpus.geometry.parameters;
        let imKorpus = 0;
        saiten.forEach(s => {
          const a = ende(s, -1), b = ende(s, 1);
          for (let i = 0; i <= 40; i++) {
            const p = a.clone().lerp(b, i / 40).applyMatrix4(inv);
            if (Math.abs(p.x) <= kp.width / 2 && Math.abs(p.y) <= kp.height / 2
                && Math.abs(p.z) <= kp.depth / 2) imKorpus++;
          }
        });

        /* 3. Abstand benachbarter Saiten (Punktabtastung, reicht bei 7 Saiten). */
        const punkte = saiten.map(s => { const a = ende(s, -1), b = ende(s, 1);
          return Array.from({ length: 41 }, (_, i) => a.clone().lerp(b, i / 40)); });
        let minAbstand = 9;
        for (let i = 0; i < punkte.length - 1; i++)
          for (const p of punkte[i]) for (const q of punkte[i + 1])
            minAbstand = Math.min(minAbstand, p.distanceTo(q));

        /* 4. Längen wachsen streng monoton zur Säule hin. */
        const laengen = saiten.map(s => +ende(s, 1).distanceTo(ende(s, -1)).toFixed(3));
        const monoton = laengen.every((l, i) => i === 0 || l > laengen[i - 1]);

        /* 5. Innenwinkel am Knoten und geschlossener Rahmen. */
        const hals = teile.hals[0], saeule = teile.saeule[0];
        const kOben = ende(korpus, 1), kUnten = ende(korpus, -1);
        const hKnoten = ende(hals, -1), hKopf = ende(hals, 1);
        const vK = kUnten.clone().sub(kOben).normalize();
        const vH = hKopf.clone().sub(hKnoten).normalize();
        const winkel = T.MathUtils.radToDeg(Math.acos(vK.dot(vH)));
        const luecke = kOben.distanceTo(hKnoten);
        const sKopf = ende(saeule, 1);
        const luecke2 = Math.hypot(hKopf.x - sKopf.x, hKopf.y - sKopf.y);

        let lambert = true;
        m.traverse(o => { if (o.material && !o.material.isMeshLambertMaterial) lambert = false; });

        return { anzahl: saiten.filter(Boolean).length, sichtbar, imKorpus,

                 luecke2: +luecke2.toFixed(3), lambert,
                 breite: +(bb.max.x - bb.min.x).toFixed(3),
                 tiefe: +(bb.max.z - bb.min.z).toFixed(3),

                 unten: +bb.min.y.toFixed(3), mat: w.matCount() };

- [ ] **Step 3: `harfe()` ersetzen.**
      In `js/models.js` den Block ab `harfe() { const g = G();` bis zum
      `return g; },` davor (`js/models.js:354-372`) vollständig ersetzen durch:

      ```js
      harfe() { const g = G();
        /* Seitenprofil in der x-y-Ebene (z ist die Tiefe), Nullpunkt am Boden,
           um x = 0 zentriert. Drei gerade Seiten: der Korpus lehnt nach hinten,
           die Säule steht senkrecht vorne, der Hals spannt oben zwischen beiden.
           Entscheidend ist der Winkel am Knoten Korpus/Hals — er betrug 158°,
           und bei 158° gibt es schlicht keine Fläche, über die Saiten spannen
           könnten: sie lagen deshalb im Resonanzkörper drin und waren unsichtbar
           (#101). Jetzt sind es 114°.
           bar() spannt einen Quader von Punkt a nach Punkt b (beide [x, y]). */
        const bar = (a, b, w, d, mat, ext = 0) => { const dx = b[0] - a[0], dy = b[1] - a[1];
          const m = box(g, w, Math.hypot(dx, dy) + ext, d, mat, (a[0] + b[0]) / 2, (a[1] + b[1]) / 2, 0);
          m.rotation.z = -Math.atan2(dx, dy); return m; };
        /* Die drei Eckpunkte sind die einzigen frei gewählten Zahlen des Rahmens.
           Richtungen, Normalen und alle vierzehn Saitenenden folgen daraus —
           wer die Proportionen ändert, ändert hier drei Punkte, nicht die
           Saiten einzeln. */
        const FUSS = [-0.06, 0.10], KNOTEN = [-0.18, 1.00], KOPF = [0.18, 1.22];
        const richtung = (a, b) => { const dx = b[0] - a[0], dy = b[1] - a[1], L = Math.hypot(dx, dy);
          return [dx / L, dy / L]; };
        const kAb = richtung(KNOTEN, FUSS);        /* Korpus, vom Knoten nach unten */
        const hAb = richtung(KNOTEN, KOPF);        /* Hals, vom Knoten zur Säule */
        const kN = [-kAb[1], kAb[0]];              /* neben dem Korpus, zur Säule hin */
        const hN = [hAb[1], -hAb[0]];              /* unter dem Hals, ins Innere */
        const versetzt = (p, n, s) => [p[0] + n[0] * s, p[1] + n[1] * s];
        const entlang = (p, r, s) => [p[0] + r[0] * s, p[1] + r[1] * s];

        box(g, 0.44, 0.08, 0.30, MAT.woodD, 0, 0.04).userData.teil = 'fuss';
        bar(FUSS, KNOTEN, 0.16, 0.24, MAT.woodL, 0.06).userData.teil = 'korpus';
        /* Saitenhalter: die schmale Leiste auf der Korpusvorderkante, in der die
           Saitenfüsse stecken. Sie liegt auf demselben Versatz wie die Füsse. */
        bar(versetzt(FUSS, kN, 0.095), versetzt(KNOTEN, kN, 0.095), 0.035, 0.16, MAT.woodD)
          .userData.teil = 'leiste';
        bar(KNOTEN, KOPF, 0.10, 0.16, MAT.woodD, 0.05).userData.teil = 'hals';
        cyl(g, 0.045, 0.05, 1.12, MAT.wood, KOPF[0], 0.66, 0, 10).userData.teil = 'saeule';
        sph(g, 0.06, MAT.gold, KOPF[0], KOPF[1] + 0.02, 0).userData.teil = 'knauf';

        /* Harfenregel: Saite i hängt am Hals im Abstand a vom Knoten und am
           Korpus im Abstand FAKTOR · a. Bei konstantem Faktor stehen alle
           Saiten nahezu parallel zueinander und werden gleichmässig länger, je
           weiter sie zur Säule wandern — genau das Bild einer Harfe. Die Füsse
           sitzen 0.10 neben der Korpusachse (Halbbreite 0.08 plus Luft), die
           Köpfe 0.045 unter der Halsachse: so tritt keine Saite in einen
           Körper ein. */
        const SAITEN = 7, FAKTOR = 1.70, K_VERSATZ = 0.10, H_VERSATZ = 0.045;
        for (let i = 0; i < SAITEN; i++) {
          const a = 0.10 + (0.38 - 0.10) * i / (SAITEN - 1);
          const fuss = versetzt(entlang(KNOTEN, kAb, FAKTOR * a), kN, K_VERSATZ);
          const kopf = versetzt(entlang(KNOTEN, hAb, a), hN, H_VERSATZ);
          bar(fuss, kopf, 0.014, 0.014, MAT.gold).userData.saite = i;
        }
        return g; },
      ```
